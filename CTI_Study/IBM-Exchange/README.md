# IBM-Exchange

Conteúdos usados para a análise feita da plataforam de CTI IBM-Exchange.

Foram extraídos manualmente todos os 121 relatórios da plataforma do dia 13/03/2026

Como conclusões pode-se retirar que:
- Em termos de utilização do formato STIX não é propriamente bem utilizada, com apenas ocorrência de 17.8% dos objetos disponíveis para uso;
- Para além da subutilização de STIX os relatórios em si têm muito pouco conteúdo, em média 12 objetos por relatório.
- 19.11% dos objetos utilizados são relações, o que mostra algum nível de correlação
- Não tem suporte _Freemium_ para automação
