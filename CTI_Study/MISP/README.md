# MISP

Conteúdos usados para a análise feita da plataforam de CTI MISP.

Como conclusões pode-se retirar que em STIX:
- Tem uma multitude de feeds (providenciadores de relatórios) que se podem adicionar à plataforma;
- De todas as pltaforams é a que aproveita melhor o formato STIX (64% dos objetos disponíveis);
- Tem poucas relações entre objetos (0.11% dos objetos são relações)
- Tem suporte API "ilimitado"

Foi, para além disso, concluído que o formato STIX que o MISP providencia é apenas a conversão do seu próprio formato (MISP) para o formato de STIX. Nessa mesma conversão foi constatado que há perda de informação, sobretudo de relações entre objetos. Por essa razão foram, a partir desta análise, considerados apenas relatórios que em formato MISP.
