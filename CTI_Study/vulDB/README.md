# VulDB

Conteúdos usados para a análise feita da plataforam de CTI VulDB.

Como conclusões pode-se retirar que:
- Não é usado o formato STIX
- Tem essencialmente dois tipos úteis de relatório, de vulnerabilidades e atividades
- Com suporte API limitado mas suficiente
- Inclui suporte de CVE e criticidade da vulnerabilidade
