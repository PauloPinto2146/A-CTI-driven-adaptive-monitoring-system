# Maltiverse

Conteúdos usados para a análise feita da plataforam de CTI Maltiverse.

Foram analisados 6 feeds do maltiverse:
- APT
- C2C
- Conti
- Cybercrime
- Malware distribution
- Malware

Como conclusões pode-se retirar que:
- Visto que Maltiverse providencia feeds como um único relatório de ameaça em STIX, acaba por ter imensos objetos por relatório (~7828 objetos por relatório);
- Em termos de utilização do formato STIX não é propriamente bem utilizada, com apenas ocorrência de 15.6% dos objetos disponíveis para uso;
- Tem imensas relações entre objetos (68.29%) o que é ótimo
- O suporte de automação é limitado mas suficiente
