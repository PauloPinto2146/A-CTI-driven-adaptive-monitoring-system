# AlienVaultOTX

Conteúdos usados para a análise feita da plataforam de CTI AlienVaultOTX.

Foram analisados 1000 _pulses_ vindos dos _Top users_ da plataforma que, no caso, são os 10 maiores contribuidores em termos quantitativos de relatórios de ameaça.
66.98% dos relatórios são de 2026 e os restantes de 2025.

Como conclusões pode-se retirar que:
- AlienVaultOTX é uma plataforma muito direcionada para indicadores de compromisso (92.62% dos objetos reportados são indicadores de compromisso);
- Em termos de utilização do formato STIX não é propriamente bem utilizada, com apenas ocorrência de 11.1% dos objetos disponíveis para uso;
- Para além da subutilização de STIX os relatórios em si têm pouco conteúdo, em média 20 objetos por relatório.
- Não existe nenhum tipo de correlação entre objetos
- Não tem suporte _Freemium_ para automação
