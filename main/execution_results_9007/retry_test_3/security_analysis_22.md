**Omitted attack patterns explanation**

- **T1190 (Exploit Public‑Facing Application)** – This technique involves exploiting network services (HTTP, SMB, etc.) and does not generate DNS query events; therefore it cannot be observed via Sysmon Event ID 22.  
- **T1021.002 (SMB/Windows Admin Shares)** – Lateral movement over SMB does not require DNS resolution and consequently produces no DNS query logs.  
- **T1021.001 (Remote Desktop Protocol)** – RDP connections are established directly to IP addresses or hostnames already resolved; the connection itself is not a DNS query event.  
- **T1569.002 (Service Execution)** – Executing services via the Service Control Manager does not inherently involve DNS lookups, so it is outside the scope of Event ID 22.  

These patterns were omitted because the Sysmon DNS query event cannot capture the activities they describe.
